# Interpretando os resultados

Quando a mineração termina (ou enquanto ainda está em andamento), você pode acessar os resultados. Esta é a tela mais importante do Super Miner — é aqui que você decide quais produtos comprar.

## As três classificações

Cada produto recebe uma classificação baseada nos seus critérios configurados em [Configurações → Custos e Critérios](../configuracoes/custos-criterios):

### ✅ Aprovado
O produto atende a **todos** os critérios mínimos de margem, ROI e demanda. São os melhores candidatos para compra.

### ⚠️ Atenção
O produto está **próximo dos limites** — atende alguns critérios mas não todos. Podem ser boas oportunidades dependendo do contexto (ex: produto com margem boa mas demanda um pouco abaixo do mínimo).

### ❌ Reprovado
O produto **não atende** aos critérios mínimos. O sistema mostra o motivo principal da reprovação.

## Métricas por produto

Para cada produto aprovado ou em atenção, você vê:

| Métrica | O que é | Como interpretar |
|---|---|---|
| **Preço de custo** | Preço no catálogo do fornecedor | Quanto você paga por unidade |
| **Preço Buybox** | Preço atual na Amazon | Quanto o produto está sendo vendido |
| **Margem** | (Preço venda − custos totais) / Preço venda | % de lucro sobre o preço de venda |
| **ROI** | Lucro / Preço de custo | % de retorno sobre o que você investiu |
| **Demanda mensal** | Estimativa de unidades vendidas/mês | Quantas unidades o mercado absorve |
| **Tendência de preço** | Histórico dos últimos 90 dias | Alta 📈 / Estável ➡️ / Queda 📉 |

## Motivos de reprovação

Para produtos reprovados, o Super Miner indica o motivo:

| Motivo | O que fazer |
|---|---|
| **Margem insuficiente** | O preço do fornecedor está alto demais — negocie ou descarte |
| **ROI insuficiente** | O retorno não compensa o investimento — verifique se há volume compensador |
| **Demanda baixa** | Poucas vendas por mês — risco de encalhe |
| **Muita concorrência** | Muitos sellers FBA — difícil ganhar o Buybox |
| **Preço em queda** | Tendência de queda de preço — margem vai piorar |

## Simulador de preço

Antes de decidir, use o **Simulador de Preço** em cada produto:

1. Clique no produto para abrir os detalhes
2. Ajuste o **preço de custo** (ex: se conseguir desconto com o fornecedor) ou o **preço de venda** (ex: se for praticar um preço diferente do Buybox atual)
3. A margem e o ROI se recalculam em tempo real

Isso é útil para simular: "se eu conseguir 10% de desconto neste produto, vale a pena?"

## Exportar resultados

No topo da tela de resultados, você pode exportar para:

- **Excel (.xlsx)**: Planilha completa com todos os produtos e métricas
- **PDF**: Relatório formatado para apresentar

:::tip Filtre antes de exportar
Use os filtros da tela para mostrar apenas os Aprovados antes de exportar — gera um relatório mais limpo para análise.
:::

## Favoritos

Clique na estrela (⭐) em qualquer produto para marcá-lo como favorito. Isso facilita identificar os produtos que você já selecionou para compra.
