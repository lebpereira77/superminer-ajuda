# Iniciando uma sessão de mineração

Com pelo menos um catálogo importado e validado, você está pronto para iniciar a mineração.

## Passo a passo

### 1. Acesse "Nova Mineração"

No menu lateral, clique em **Nova Mineração** (ou clique no botão de mesmo nome no painel principal).

### 2. Selecione o catálogo

Escolha o fornecedor e o catálogo que deseja analisar. Você pode selecionar mais de um catálogo na mesma sessão.

### 3. Escolha o tipo de mineração

| Tipo | Quando usar |
|---|---|
| **Buybox** | Você quer competir diretamente nos produtos que já têm demanda na Amazon — foco em ganhar o Buybox |
| **Oportunidades genéricas** | Você busca produtos com demanda comprovada mas menor concorrência |

Para a maioria dos sellers iniciando, **Buybox** é o tipo recomendado.

### 4. Configurações opcionais

Antes de iniciar, você pode ajustar:

| Opção | Descrição |
|---|---|
| **Nome da sessão** | Um nome para identificar esta análise (ex: "Catálogo Jan 2026 — Fornecedor X") |
| **Filtro de marca** | Se quiser excluir ou incluir apenas produtos de determinada marca |
| **Máximo de produtos** | Limite o número de produtos analisados (útil para testes) |
| **Lista de ASINs** | Se você já tem uma lista de ASINs da Amazon para cruzar com o catálogo, faça o upload aqui |
| **Instruções para a IA** | Contexto adicional para o sistema de matching (ex: "produtos de beleza, foco em cosméticos importados") |

### 5. Inicie a mineração

Clique em **Iniciar Mineração**. A tela de progresso mostrará em tempo real o que está acontecendo:

- Descobrindo produtos no banco da Amazon
- Encontrando matches
- Calculando viabilidade

### 6. Acompanhe ou aguarde

Você pode acompanhar o progresso na tela ou simplesmente fechar e voltar depois. A sessão continuará rodando no servidor.

## Dicas para melhores resultados

- **Catálogos validados**: Certifique-se de que o catálogo foi validado corretamente antes de minerar — dados incorretos geram matches ruins
- **Instruções para IA**: Se o catálogo tem produtos de nicho específico (ex: ferramentas industriais, cosméticos), adicione esse contexto nas instruções — melhora bastante o matching
- **Sessões menores primeiro**: Para um novo fornecedor, comece com um limite de 100–200 produtos para avaliar a qualidade dos matches antes de processar o catálogo completo
