# Cadastrando um fornecedor

Antes de importar qualquer catálogo, você precisa cadastrar o fornecedor ao qual ele pertence. O cadastro é simples e serve para organizar seus catálogos por origem.

## Como cadastrar

1. No menu lateral, clique em **Fornecedores**
2. Clique em **Novo Fornecedor** (botão no canto superior direito)
3. Preencha os campos:

| Campo | Obrigatório | Descrição |
|---|---|---|
| **Nome** | Sim | Nome do fornecedor — use algo que você reconheça facilmente |
| **Contato** | Não | E-mail ou telefone do fornecedor |
| **Observações** | Não | Qualquer informação relevante sobre o fornecedor |

4. Clique em **Salvar**

O fornecedor aparecerá na lista principal. A partir daí, você pode importar catálogos para ele.

## Gerenciando fornecedores

Na tela de Fornecedores você pode:

- **Ver todos os catálogos** de cada fornecedor
- **Editar** os dados cadastrais clicando no ícone de lápis
- **Excluir** um fornecedor — atenção: isso remove o fornecedor e todos os seus catálogos permanentemente

## Boas práticas

- Use o nome real do fornecedor para facilitar a identificação nos resultados
- Você pode ter múltiplos catálogos por fornecedor (ex: catálogo de janeiro, catálogo de fevereiro)
- Não há limite de fornecedores cadastrados

:::tip Próximo passo
Com o fornecedor criado, o próximo passo é [importar o catálogo](./importando-catalogo) com os produtos para análise.
:::
