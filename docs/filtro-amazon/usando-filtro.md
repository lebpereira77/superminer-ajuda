# Super Filter

O Super Filter é uma ferramenta de pesquisa avançada que permite explorar o banco de dados da Amazon Brasil com filtros precisos. Use-o para descobrir oportunidades por conta própria, sem precisar de um catálogo de fornecedor.

## Para que serve

Enquanto a mineração parte do catálogo do fornecedor e vai para a Amazon, o Super Filter faz o caminho inverso: você define as características do produto que quer encontrar e o sistema retorna os produtos da Amazon que se encaixam.

**Casos de uso comuns:**
- Encontrar produtos em uma categoria específica com boa demanda e pouca concorrência
- Identificar produtos com BSR alto (muitas vendas) e poucas avaliações (mercado em crescimento)
- Checar se um produto específico tem demanda antes de fechar com um fornecedor

## Filtros disponíveis

### Preço
- **Preço mínimo / máximo do Buybox** — Faixa de preço de venda na Amazon

### Vendas e Demanda
- **Vendas mensais mínimas** — Filtra apenas produtos com pelo menos X unidades vendidas por mês
- **BSR máximo** — Rank de melhores vendedores (quanto menor o número, mais vende)

### Avaliações
- **Nota mínima** — Ex: apenas produtos com 4 estrelas ou mais
- **Número mínimo de avaliações** — Ex: pelo menos 50 avaliações (mercado validado)

### Concorrência
- **Máximo de vendedores FBA** — Quanto menos vendedores FBA, mais fácil é entrar

### Categoria
- Selecione uma ou mais categorias da Amazon Brasil para filtrar

### Data de listagem
- **Listado a partir de / até** — Encontre produtos novos (listados recentemente) ou mais antigos

## Como usar

1. Acesse **Super Filter** no menu lateral
2. Configure os filtros desejados
3. Clique em **Buscar**
4. Os resultados aparecem na tabela abaixo

## Analisando um produto

Clique em qualquer produto dos resultados para ver:

- **Histórico de preços** (últimos 90 dias) em gráfico — mostra se o preço está estável ou oscilando
- **Histórico de demanda** — tendência de vendas ao longo do tempo
- **Cálculo de viabilidade** — margem e ROI baseados nos seus critérios configurados

## Importar lista de ASINs

Se você tem uma lista de ASINs (obtida por outros meios, como de um concorrente ou de outra ferramenta), pode importar diretamente via Excel para analisar em lote.

## Exportar resultados

Clique em **Exportar** para baixar os resultados filtrados em Excel — útil para montar um briefing de fornecedores.

## Combinação com mineração

Uma estratégia eficaz é:

1. Usar o Super Filter para identificar categorias e produtos com boa demanda
2. Levar essa lista para a reunião com fornecedores — busque especificamente os produtos com demanda comprovada
3. Após fechar, importe o catálogo e mine para confirmar a margem

:::tip Dica de uso
Para achar oportunidades ocultas, tente: BSR máximo 50.000 + vendedores FBA máximo 3 + avaliações mínimas 100. Produtos com boa demanda e baixíssima concorrência FBA são raros mas existem.
:::
